# System Workflow

## Customer Workflow

1. Customer registers an account.
2. Customer logs into the system.
3. Customer browses available services.
4. Customer searches or filters a service.
5. Customer selects a service provider.
6. Customer selects preferred date and time.
7. Customer enters service address/details.
8. Customer submits booking.
9. Booking status becomes "Pending".
10. Service provider receives the request.
11. Provider accepts or rejects the request.
12. If accepted, booking status becomes "Accepted".
13. Provider performs the service.
14. Status becomes "In Progress".
15. After completion, status becomes "Completed".
16. Customer can provide a rating and review.

## Service Provider Workflow

1. Provider registers.
2. Provider creates a service profile.
3. Provider adds service information.
4. Provider sets availability.
5. Provider receives booking requests.
6. Provider accepts or rejects requests.
7. Provider updates booking status.
8. Provider completes the service.
9. Completed booking is stored in booking history.

## Admin Workflow

1. Admin logs into the system.
2. Admin views dashboard.
3. Admin manages customers.
4. Admin manages service providers.
5. Admin manages service categories.
6. Admin monitors bookings.
7. Admin manages reviews.
8. Admin monitors overall system activity.
