# Use Case Diagram

## Actors

The system has three main actors:

1. Customer
2. Service Provider
3. Administrator

## Customer Use Cases

- Register
- Login
- Manage Profile
- Browse Services
- Search Services
- Filter Services
- View Service Provider
- Book Service
- Select Date and Time
- Track Booking
- Cancel Booking
- View Booking History
- Give Rating
- Write Review

## Service Provider Use Cases

- Register
- Login
- Manage Profile
- Manage Services
- Set Availability
- View Booking Requests
- Accept Booking
- Reject Booking
- Update Booking Status
- View Booking History

## Admin Use Cases

- Login
- Manage Customers
- Manage Service Providers
- Approve/Reject Providers
- Manage Service Categories
- Manage Services
- Manage Bookings
- Manage Reviews
- Monitor System Activities
